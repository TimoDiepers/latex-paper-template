# Notes for AI assistants

This repository holds a scientific paper written in LaTeX. The README describes the
workflow and the tools.

When drafting, editing or reviewing any manuscript text (`manuscript/manuscript.tex`,
`revision_*/manuscript_annotated.tex`, `revision_*/response_to_reviewers.tex`), read
[WRITING_GUIDE.md](WRITING_GUIDE.md) first and follow it. When asked to review, work
through its checklist (Section 11).

Never edit anything under a `submission/` folder: it is generated and rebuilt on every
run.
